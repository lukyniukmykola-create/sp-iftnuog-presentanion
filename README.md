# Презентація Студентського парламенту ІФНТУНГ

Вебпрезентація (16 слайдів) для залучення нових студентів.
Керування: стрілки ← →, пробіл, клік або свайп на телефоні.

## Структура
- `index.html` — сама презентація (один файл)
- `assets/img/` — фотографії
- `assets/logo.png` — грифон (логотип)
- `downloads/studparlament_ifntung.pptx` — версія для PowerPoint
- `.nojekyll` — потрібен для GitHub Pages

## Публікація на GitHub Pages
1. Створи репозиторій на github.com (кнопка **New**, наприклад `studparlament`), вибери **Public**.
2. Натисни **uploading an existing file** і перетягни **весь вміст** цієї папки (разом із `assets`, `downloads` і `.nojekyll`). Натисни **Commit changes**.
3. Відкрий **Settings → Pages**. У розділі **Build and deployment** вибери **Deploy from a branch**, гілку **main** і папку **/ (root)**, натисни **Save**.
4. Через 1–2 хвилини сайт буде за адресою `https://ТВІЙ_НІК.github.io/studparlament/`.

## Інший хостинг
Підійде будь-який статичний хостинг: завантаж вміст папки в корінь сайту.
- **Netlify:** app.netlify.com/drop — перетягни папку.
- **Vercel / Cloudflare Pages:** підключи репозиторій, налаштування збірки не потрібні.

## Як змінити
- Текст: відкрий `index.html` у будь-якому редакторі й заміни потрібні слова.
- Фото: заміни файл у `assets/img/` на інший із тією самою назвою.
